# 🔪 DBD Companion – Anleitung
von **FGSeRaser** · https://github.com/FGSeRaser

## Starten
1. ZIP entpacken (z. B. nach `Dokumente\DBD Companion`).
2. **DBD Companion.exe** starten. Windows fragt beim ersten Mal evtl. „Unbekannter Herausgeber“ → *Weitere Informationen → Trotzdem ausführen*.
3. Deine Challenges aus der alten Version werden automatisch übernommen.

## Overlay im Spiel
1. In **Dead by Daylight**: *Einstellungen → Grafik → Anzeigemodus* → **Fenster-Vollbild**.
2. Im Companion oben rechts **„🖥 Overlay: AUS“** anklicken → wird grün = an.
3. Im Tab **🖥 Overlay** wählst du, *was* angezeigt wird (Timer, Challenges, Build, Zähler, Text), und ziehst es in der Vorschau an die richtige Stelle. Größe, Farben und Deckkraft stellst du daneben ein.
4. Direkt im Spiel verschieben: **„✋ Im Spiel verschieben“** (oder Hotkey, Standard **Strg+Alt+E**) → Teile mit der Maus ziehen → nochmal drücken, dann sind sie wieder durchklickbar.
5. Schließt du das Fenster, während das Overlay läuft, bleibt der Companion unten rechts im **Tray**. Rechtsklick → *Beenden*.

## Challenge anpinnen
Tab **🎯 Challenges** → Challenge öffnen → **📌 Ans Overlay anpinnen**. Du kannst mehrere anpinnen.
Im Spiel per Hotkey abhaken (Standard): **Strg+Alt+S** geschafft · **Strg+Alt+V** Versuch nicht geschafft · **Strg+Alt+↓** rückgängig · **Strg+Alt+→** nächste angepinnte.

## Hotkeys selbst wählen
- **⚙ Einstellungen → Globale Hotkeys**: Feld anklicken, Taste oder Kombination drücken (z. B. F9, Num 5, Strg+Alt+F). **Entf** löscht, **Esc** bricht ab.
- **⏱ Timer**: jeder Timer und jeder Zähler (+1/−1) hat ein eigenes Hotkey-Feld.
- **Abfangen** (Standard): Das Spiel bekommt die Taste nicht. **Durchlassen**: Die Taste wirkt im Spiel *und* im Companion – praktisch, wenn du z. B. einen Timer auf dieselbe Taste legen willst, die du im Spiel sowieso drückst.

## Mit EntityDex (Handy) verbinden
1. EntityDex-App aufs Handy (APK unter https://github.com/FGSeRaser/EntityDex/releases) oder https://fgseraser.github.io/EntityDex/ öffnen.
2. Dort im Tab **🎯 Challenges** ein Konto erstellen (E-Mail + Passwort) und die Bestätigungs-Mail anklicken.
3. Im Companion **⚙ Einstellungen → ☁ Konto & Sync** mit derselben E-Mail anmelden.
Ab jetzt landen Challenges, die du am Handy anlegst oder für den Stream planst (📅), automatisch im Companion – und umgekehrt. Heute geplante Challenges zeigt dir die Startseite.

## Streamer-Modus (⚙ Einstellungen)
- **OBS-Browserquelle**: Haken setzen → in OBS *Quelle hinzufügen → Browser* → URL `http://localhost:8833/`, Breite/Höhe wie dein Bildschirm (z. B. 1920 × 1080). Die Widgets erscheinen im Stream scharf und durchsichtig.
- **Ingame-Overlay im Stream verstecken**: Du siehst das Overlay, deine Zuschauer nicht (z. B. wenn du stattdessen die OBS-Quelle nutzt, damit nichts doppelt ist).
- **Companion-Fenster verstecken**: Bei einer Bildschirmaufnahme ist das Companion-Fenster unsichtbar.

## Daten
Killer, Survivor, Perks (deutsch/englisch), Bilder, Maps und Builds kommen live aus **EntityDex** (https://fgseraser.github.io/EntityDex/), das sich alle 3 Stunden aktualisiert. Ohne Internet nutzt der Companion die mitgelieferten Daten.
Sichern/Wiederherstellen: **⚙ Einstellungen → Daten**.

## Probleme?
- **Overlay nicht sichtbar** → DBD steht auf echtem Vollbild. Auf *Fenster-Vollbild* stellen.
- **Hotkey geht nicht** → Taste ist evtl. schon belegt (z. B. von Discord/OBS). Andere Taste wählen oder auf *Durchlassen* stellen.
- **Fenster bleibt weiß** → „Microsoft Edge WebView2 Runtime“ installieren: https://developer.microsoft.com/microsoft-edge/webview2/
